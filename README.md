# 🚗 CarAdvisor

Aplicación diseñada para que los usuarios puedan llevar un control de su vehículo a nivel mecánico en tiempo real, con asistencia oportuna para el día a día y emergencias.

## 🛠️ Tecnologías
* **Backend:** Java / Spring Boot
* **Mobile:** React Native / Expo Router

## 🚀 Inicio Rápido

### Móvil (`car-advisor-mobile`)
```bash
cd car-advisor-mobile
npm install
npx expo start --web
